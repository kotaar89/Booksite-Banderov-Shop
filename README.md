# 📚 Интернет-магазин книг «БукРид» (BookRead)

Полноценный базовый проект интернет-магазина книг.
- **Frontend**: Angular (Standalone Components, Signals, Router, FormsModule, HttpClient)
- **Backend**: PHP (REST API, PDO, поддержка CORS, JSON)
- **База данных**: MySQL для MAMP / phpMyAdmin (дамп `database/schema.sql`)

---

## 🚀 Пошаговая инструкция по запуску

### Шаг 1: Запуск MAMP и импорт базы данных

1. Запустите программу **MAMP** на вашем компьютере и нажмите **«Start Servers»**.
2. Откройте **phpMyAdmin** (через стартовую страницу MAMP или по адресу `http://localhost/phpmyadmin` / `http://localhost:8888/phpmyadmin`).
3. В верхнем меню выберите вкладку **«Импорт»** (Import).
4. Нажмите кнопку **«Выберите файл»** и укажите файл из проекта:
   `bookstore/database/schema.sql`
5. Нажмите кнопку **«Вперёд»** (Импорт) внизу страницы.
   > База данных `bookstore_db` с таблицами `categories`, `books`, `users`, `orders`, `order_items` и начальными книгами создастся автоматически!

---

### Шаг 2: Запуск PHP бэкенда

Самый простой и быстрый способ запустить PHP бэкенд:
1. Откройте терминал (PowerShell или Командную строку).
2. Перейдите в корневую папку проекта:
   ```bash
   cd "C:\Users\whyte\.gemini\antigravity\scratch\bookstore"
   ```
3. Запустите встроенный PHP сервер:
   ```bash
   php -S localhost:8000 -t backend
   ```
   *Сервер запустится по адресу `http://localhost:8000/api`.*

*(Либо, если вы используете стандартный веб-сервер MAMP, поместите папку проекта в `htdocs` MAMP, например `C:\MAMP\htdocs\bookstore`, и при необходимости скорректируйте URL в `frontend/src/app/config/api.config.ts`).*

---

### Шаг 3: Запуск Angular фронтенда

1. Откройте второе окно терминала.
2. Перейдите в папку `frontend`:
   ```bash
   cd "C:\Users\whyte\.gemini\antigravity\scratch\bookstore\frontend"
   ```
3. Запустите проект:
   ```bash
   npm start
   ```
4. Откройте в браузере:
   👉 **http://localhost:4200**

## 🌟 Реализованные возможности

1. **Главная страница**:
   - Промо-баннер с актуальной скидкой на книгу недели.
   - Блок преимуществ магазина.
   - Секция «Акции и специальные предложения» (книги с бейджем скидки и старой зачеркнутой ценой).
   - Быстрый переход по популярным категориям.
   - Секция «Популярное и выбор читателей».
   - Модальное окно просмотра деталей книги и добавления в корзину.

2. **Каталог**:
   - Фильтрация по жанрам/категориям (Все, Классика, Фантастика, Бизнес, Детективы...).
   - Поиск в реальном времени по названию, автору или ключевым словам.
   - Быстрый переключатель «Только со скидкой».
   - Сортировка (сначала дешевле, сначала дороже, по рейтингу).
   - Быстрый сброс фильтров.

3. **Корзина**:
   - Список добавленных книг с обложкой, названием, ценой за штуку и общей стоимостью.
   - Удобные кнопки увеличения и уменьшения количества (`+`, `-`) и удаление.
   - Автоматический расчет стоимости доставки (бесплатно от 2000 ₽).
   - Синхронизация с бейджем в шапке сайта.
   - Сохранение в `localStorage` (корзина не сбрасывается при обновлении страницы).

4. **Оформление заказа**:
   - Автозаполнение данных получателя, если пользователь авторизован.
   - Выбор способа оплаты (картой онлайн, СБП по QR-коду, при получении курьеру).
   - Валидация полей.
   - Создание заказа в базе данных MySQL (связанные таблицы `orders` и `order_items`).
   - Очистка корзины и страница успешного оформления с номером заказа.

5. **Личный кабинет**:
   - Просмотр личных данных и статистики (количество заказов, общая сумма покупок).
   - Вкладка «Мои заказы» с историей, статусами заказов, датами и полным списком купленных книг.
   - Вкладка «Настройки профиля» с возможностью отредактировать имя, телефон и адрес доставки.
   - Кнопка выхода из системы.
